# Personel Verisi İşleme ve Görselleştirme

Bu proje, Python kullanılarak CSV ve XML formatındaki personel verilerinin işlenmesi, birleştirilmesi, temizlenmesi ve görselleştirilmesi amacıyla geliştirilmiştir.

## Kullanılan Teknolojiler
- Python
- Pandas
- Matplotlib
- CSV
- XML

## Proje İçeriği
- CSV ve XML dosyalarından verilerin okunması
- Farklı veri kaynaklarının birleştirilmesi
- Verilerin temizlenmesi ve düzenlenmesi
- Personel verilerinin analiz edilmesi
- Elde edilen sonuçların grafiklerle görselleştirilmesi

## Dosyalar
- `veri_bilimine_giris_proje.py` – Projenin Python kaynak kodu
- `Personel.csv` – CSV veri dosyası
- `Personel.xml` – XML veri dosyası

## Amaç
Bu projede farklı veri formatlarıyla çalışma, veri işleme ve temel veri analizi konularında uygulamalı deneyim kazanılması amaçlanmıştır.
